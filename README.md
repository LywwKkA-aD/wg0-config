# wg0-config

This repository contains scripts to automate the installation and configuration of WireGuard VPN on Debian 12.10. The repository is divided into two main parts: the server setup and the client setup.

## Overview

- **Server Setup**: Scripts to set up and configure a WireGuard VPN server.
- **Client Setup**: Scripts to set up and configure a WireGuard VPN client.

## Getting Started

### Server

To set up the WireGuard VPN server, navigate to the [server directory](server/README.md) and follow the instructions provided.

### Client

To set up the WireGuard VPN client, navigate to the [client directory](client/README.md) and follow the instructions provided.
